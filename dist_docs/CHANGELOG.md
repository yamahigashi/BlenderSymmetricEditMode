# Changelog

## 0.9.0 — 2026-08-18 (initial release / 初回リリース)

Mirror native Edit Mode operations across one mesh-symmetry axis without a Mirror modifier.
Mirror modifier を使わず、1 本のメッシュ対称軸を基準にネイティブ編集操作をミラーします。

Supported operations / 対応操作:

- Knife, Loop Cut, Offset Edge Loop Cut
- Extrude (E / toolbar Extrude tools / Alt+E)
- Rip (V / Alt+V)
- Vertex Connect and Merge (J / M)
- Delete / Dissolve / Collapse (X / Del / Ctrl+X)
- Inset Faces (I / toolbar)
- Bevel (Ctrl+B / Ctrl+Shift+B / toolbar)

Requirements: Blender 4.2 LTS or later. Tested on Blender 4.2 and 5.2.
See KNOWN_LIMITATIONS for unsupported routes and failure behavior.

動作環境: Blender 4.2 LTS 以降。Blender 4.2 / 5.2 でテスト済み。
非対応経路と失敗時の挙動は KNOWN_LIMITATIONS を参照してください。
